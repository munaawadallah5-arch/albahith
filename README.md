# موقع «الباحث» — النسخة المستقلة

مرصد المؤتمرات والمسابقات والجوائز البحثية. هذه النسخة لا تعتمد على Claude ولا على أي خدمة مدفوعة: أربعة ملفات ترفعينها على أي استضافة مواقع.

## ملفات الموقع

| الملف | ما هو |
|---|---|
| `index.html` | صفحة الموقع |
| `app.js` | برمجة الموقع (المجالات، التقويم، المنبّه…). لا تحتاجين إلى تعديله |
| `events.js` | **ملف الإعلانات**: هذا ما تعدّلينه لإضافة الإعلانات |
| `logo.svg` | الشعار، ويظهر أيضًا في تبويب المتصفح |
| `updater/` و `.github/workflows/` | التحديث التلقائي للإعلانات (اختياري، انظري قسمه أدناه) |

لتجربة الموقع على جهازك قبل رفعه: افتحي `index.html` بالمتصفح مباشرة.

## رفع الموقع على GitHub Pages (مجانًا)

1. أنشئي حسابًا في github.com إن لم يكن لديك حساب.
2. اضغطي **New repository**، وسمّيه مثلًا `albahith`، واختاري **Public**، ثم **Create repository**.
3. في صفحة المستودع اضغطي **Add file › Upload files**، واسحبي الملفات الأربعة (ومعها هذا الدليل إن شئتِ)، ثم **Commit changes**.
4. افتحي **Settings › Pages**. في **Source** اختاري **Deploy from a branch**، ثم الفرع **main** والمجلد **/ (root)**، واضغطي **Save**.
5. بعد دقيقة أو دقيقتين يصبح الموقع على العنوان:
   `https://اسم-حسابك.github.io/albahith/`

**بديل أسرع:** في app.netlify.com/drop اسحبي مجلد الموقع كاملًا، فيُنشر فورًا ويعطيك رابطًا.

## إضافة إعلان جديد

**الطريقة الأولى، من داخل الموقع:**
1. املئي نموذج «إضافة إعلان» أسفل الصفحة واضغطي «حفظ الإعلان». يظهر الإعلان لك وحدك في متصفحك.
2. اضغطي «تنزيل ملف الإعلانات المحدّث»، فينزل ملف `events.js` جديد فيه كل الإعلانات.
3. ارفعيه على GitHub مكان الملف القديم (**Add file › Upload files**، ثم **Commit changes**). بعد دقيقة يراه كل الزوار.

**الطريقة الثانية، بتعديل الملف مباشرة:** افتحي `events.js` على GitHub، واضغطي أيقونة القلم، وانسخي أي إعلان (السطر الذي يبدأ بـ `{` وينتهي بـ `}`) والصقيه قبل القوس الأخير `]`، وضعي فاصلة `,` بين الإعلانات، ثم عدّلي القيم.

قواعد ملف الإعلانات:
- `id` مختلف لكل إعلان، بحروف إنجليزية وأرقام وشرطات، مثل `mesa-2027`.
- التواريخ بصيغة `"2027-03-15"`. احذفي أي تاريخ غير معلن.
- مفاتيح التواريخ: `announced` الإعلان، `abstract` تسليم الملخصات، `paper` تسليم البحث أو آخر موعد للتقديم، `notify` إعلان القبول أو النتائج، `start` بدء الانعقاد أو الحفل، `end` نهايته.
- `kind` واحد من: مؤتمر، جائزة، مسابقة، منحة، مدرسة صيفية/شتوية.
- `fields` من قائمة المجالات في الموقع، مكتوبة بالحرف نفسه (مثل `"فلسفة"`، `"دراسات إسلامية"`).

## كيف يعمل التذكير

- **«أضف للتقويم»** بجانب كل موعد: يضيفه إلى تقويم Google، فينبّهك هاتفك حسب إعدادات التنبيه فيه.
- **«تنزيل ملف التقويم»**: ينزّل ملف `albahith.ics` بالمواعيد التي تتابعينها (أو مواعيد مجالاتك)، وفي كل موعد تنبيه قبله بالمدة التي اخترتِها. افتحيه في تقويم آبل أو Outlook أو Google.
- **«تشغيل التنبيه»**: يرنّ ويُظهر إشعارًا على الجهاز ما دامت الصفحة مفتوحة.

اختيارات كل زائر (مجالاته، والإعلانات التي يتابعها، ومدة التنبيه) تُحفظ في متصفحه هو، ولا تُرسل إلى أي مكان.

## التحديث التلقائي للإعلانات

مهمة مجدولة على GitHub تعمل كل يوم إثنين (ويمكنك تشغيلها يدويًا متى شئتِ)، فتبحث عن إعلانات جديدة لها موعد قادم، وتضيفها إلى `events.js` بعد حذف المكرر وما انتهى موعده.

### اختيار الطريقة

كل الإعدادات في الملف `updater/settings.json`، وأهمها سطران:

- **`"mode"`**، طريقة الجمع:
  - `"free"`: **المجانية** (الافتراضية). تقرأ مواقع إعلانات منشورة، مثل قوائم دعوات الأوراق في WikiCFP وموقع جامعة بنسلفانيا. لا تكلّف شيئًا، لكن أغلب ما تجده بالإنجليزية، ونادرًا ما تجد الإعلانات العربية.
  - `"ai"`: **البحث الذكي** بمفتاح Claude API. يبحث في الويب بالعربية والإنجليزية في مجالاتك، ويستخرج المواعيد والروابط الرسمية. أشمل بكثير، ويكلّف مبلغًا صغيرًا عن كل تشغيل (ثمن عمليات البحث والمعالجة).
  - `"both"`: الطريقتان معًا.
  إذا اخترتِ `ai` أو `both` ولم يكن المفتاح موجودًا، تعمل المهمة بالطريقة المجانية وتنبّهك في تقريرها.
- **`"review"`**:
  - `true` (الافتراضي): لا يُنشر شيء قبل موافقتك. تقترح المهمة الإعلانات الجديدة في **طلب دمج (Pull Request)** فيه تقرير بكل إعلان ورابطه ومواعيده، فتراجعينه وتضغطين **Merge** لنشره، أو **Close** لرفضه.
  - `false`: تُنشر الإعلانات الجديدة مباشرة.

### مواقع الجامعات ومراكزها البحثية

في `updater/settings.json` قائمة `universities` فيها 28 جامعة عربية، لكل منها اسمها ونطاق موقعها (`domain`). ويدخل في البحث كل ما تحت هذا النطاق: الكليات، والمراكز والمعاهد البحثية التابعة للجامعة، والمؤتمرات المنشورة على مواقع فرعية مثل `conf.ksu.edu.sa`.

- **في البحث الذكي:** يبحث في مواقع هذه الجامعات نفسها عن مؤتمرات وملتقيات وندوات ودعوات للمشاركة وجوائز ومسابقات تنظمها، بالعربية أولًا ثم بالإنجليزية. يجري ذلك على دفعات، 8 جامعات في كل بحث، إلى جانب البحث العام.
- **في الطريقة المجانية:** لا يستطيع البحث في موقع كامل، لكنه يقرأ أي صفحة مؤتمرات أو فعاليات تضعين رابطها في `events_pages`، ويلتقط منها روابط المؤتمرات والجوائز ومواعيدها. مثال:
  `{"name": "جامعة قطر", "domain": "qu.edu.qa", "place": "الدوحة، قطر", "events_pages": ["https://رابط-صفحة-الفعاليات"], "enabled": true}`
- **لإضافة جامعة:** انسخي سطرًا وعدّلي الاسم والنطاق، والنطاق دون `https://` ودون `www.`. ولإيقاف جامعة اجعلي `"enabled": false`.
- **للتحكم في التكلفة** في البحث الذكي: `universities_per_search` (عدد الجامعات في كل بحث)، و`searches_per_university_group` (عدد عمليات البحث لكل دفعة)، و`general_search` (اجعليه `false` للبحث في مواقع الجامعات وحدها).

وفي الملف أيضًا: المجالات التي يُبحث فيها (`fields`)، وأقصى عدد يضاف في كل مرة، وحذف الإعلانات القديمة تلقائيًا، وتعليمات إضافية للبحث الذكي، وقائمة مصادر الطريقة المجانية.

### التفعيل (مرة واحدة)

1. ارفعي المجلد `updater` إلى المستودع (**Add file › Upload files**، واسحبي المجلد كاملًا).
2. ملف المهمة في مجلد مخفي، فأنشئيه من GitHub مباشرة: **Add file › Create new file**، واكتبي في خانة الاسم بالضبط `.github/workflows/update-events.yml`، والصقي محتوى الملف الذي بالاسم نفسه في الحزمة، ثم **Commit changes**.
3. في **Settings › Actions › General**، تحت **Workflow permissions**: اختاري **Read and write permissions**، وفعّلي **Allow GitHub Actions to create and approve pull requests**، ثم **Save**.
4. للتجربة: افتحي تبويب **Actions**، ثم **تحديث إعلانات الباحث**، ثم **Run workflow**. بعد دقائق تجدين النتيجة في تبويب **Pull requests**، أو تقرير التشغيل في **Actions** إن لم يجد جديدًا.

### تفعيل البحث الذكي

1. أنشئي حسابًا في Claude Console على console.anthropic.com، وأضيفي رصيدًا، ثم أنشئي مفتاح API.
2. فعّلي البحث في الويب لحسابك من إعدادات Claude Console (يشترط ذلك مسؤول الحساب).
3. في المستودع على GitHub: **Settings › Secrets and variables › Actions › New repository secret**. الاسم `ANTHROPIC_API_KEY`، والقيمة المفتاح. يبقى المفتاح سرًا لا يظهر لأحد ولا يُكتب في الملفات.
4. في `updater/settings.json` غيّري `"mode": "free"` إلى `"mode": "ai"` أو `"mode": "both"`.

للتحكم في التكلفة: خفّضي `max_searches` (عدد عمليات البحث في كل تشغيل).

### ملاحظات

- **ما يُجمع آليًا قد يخطئ** في تاريخ أو مجال، ولهذا المراجعة مفعّلة افتراضيًا.
- **مصادر الطريقة المجانية** مواقع خارجية قد يتغير شكلها. لم أستطع اختبارها مباشرة وقت إعدادها، فإن ذكر تقرير التشغيل خطأ في مصدر ما، فأوقفيه بجعل `"enabled": false`، أو أضيفي أي خلاصة RSS بالشكل نفسه.
- الإعلانات التي تضيفها المهمة فيها حقل `"source"` يذكر من أين جاءت.

## ربط اسم نطاق خاص (اختياري)

اشتري اسم نطاق من أي مسجّل نطاقات، ثم في **Settings › Pages › Custom domain** اكتبيه، وأضيفي في إعدادات النطاق السجلات التي يطلبها GitHub (موضحة في صفحة GitHub Pages نفسها).
